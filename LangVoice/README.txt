LangVoice - โปรแกรมพูดบอกภาษาเมื่อสลับแป้นพิมพ์ ไทย / English
================================================================

วิธีติดตั้ง
-----------
1. แตกไฟล์ zip ไปไว้ในโฟลเดอร์ใดก็ได้ (เช่น Downloads\LangVoice)
2. ดับเบิลคลิก install.bat
   - ถ้ามีหน้าต่าง "Windows protected your PC" ขึ้นมา ให้กด More info > Run anyway
3. เสร็จแล้วจะมีไอคอน TH (สีแดง) หรือ EN (สีน้ำเงิน) ที่มุมขวาล่างข้างนาฬิกา
   (ถ้าไม่เห็น ให้กดลูกศร ^ ข้างนาฬิกา)
4. ลองกดปุ่มสลับภาษา (ตัวหนอน ~ หรือ Alt+Shift หรือ Win+Space) จะได้ยินเสียง "ไทย" / "English"

โปรแกรมจะเปิดเองทุกครั้งที่เปิดเครื่อง ไม่ต้องติดตั้งอะไรเพิ่ม
(ตัวติดตั้งจะคอมไพล์โปรแกรมด้วย .NET Framework ที่มากับ Windows 10/11 อยู่แล้ว)

เมนูคลิกขวาที่ไอคอน
--------------------
- ปิดเสียงชั่วคราว
- แจ้งเตือนเมื่อสลับหน้าต่างด้วย (ถ้าปิด จะพูดเฉพาะตอนกดสลับภาษาในหน้าต่างเดิม)
- เลือกเสียงพูด
    * เสียงผู้หญิง (เปรมวดี / Jenny)   <- ค่าเริ่มต้น
    * เสียงผู้ชาย (นิวัฒน์ / Andrew)
    * เสียงที่อัด/บันทึกเอง
  เลือกแล้วจะเล่นเสียงให้ฟังทันที และจำค่าไว้
- ทดสอบเสียง ไทย / English
- เปลี่ยนเสียง / อัดเสียงเอง...
- ออกจากโปรแกรม

เสียงชายและหญิงเป็นเสียงสังเคราะห์แบบ Neural ของ Microsoft ที่สร้างไว้ให้แล้วในโฟลเดอร์ voices
ไม่ต้องติดตั้งเสียงภาษาไทยในเครื่อง และไม่ต้องต่ออินเทอร์เน็ต

อยากใช้เสียงของตัวเอง
---------------------
คลิกขวาที่ไอคอน > "เปลี่ยนเสียง / อัดเสียงเอง..."  (หรือดับเบิลคลิก make-sounds.bat)
- กด R เพื่ออัดเสียงจากไมโครโฟน (Enter เริ่ม > พูด > Enter หยุด) โปรแกรมตัดช่วงเงียบและปรับความดังให้
- กด T บันทึกเป็นเสียง "ไทย" หรือ E บันทึกเป็นเสียง "English"
  LangVoice จะสลับไปใช้ "เสียงที่อัด/บันทึกเอง" ให้อัตโนมัติ
หรือวางไฟล์ thai.wav / english.wav ไว้ในโฟลเดอร์ sounds แล้วรัน install.bat อีกครั้ง

ถอนการติดตั้ง
--------------
ดับเบิลคลิก uninstall.bat
(หรือเปิด %LOCALAPPDATA%\LangVoice แล้วรัน uninstall.ps1)

ไฟล์ที่ติดตั้ง
--------------
%LOCALAPPDATA%\LangVoice\LangVoice.exe, thai.wav, english.wav, settings.ini
Startup shortcut: shell:startup\LangVoice.lnk
